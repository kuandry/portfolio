# Portfólio profissional

Portfólio profissional de **Douglas Santos**, Desenvolvedor Full Stack, desenvolvido com HTML5 e CSS3 para a disciplina **Design Profissional**.

## Sobre o projeto

Este repositório contém o meu portfólio profissional, uma página única com apresentação, formação, competências, projetos, currículo e contato. Ele foi criado como atividade da disciplina **Design Profissional** e publicado gratuitamente no GitHub Pages.

## Objetivos

- Apresentar minha trajetória, formação e competências de forma objetiva e verdadeira.
- Reunir meus projetos, explicando qual foi a minha participação em cada um.
- Disponibilizar meu currículo e meus canais de contato.
- Praticar HTML semântico, CSS responsivo, acessibilidade, versionamento com Git e publicação no GitHub Pages.

## Tecnologias utilizadas

- **HTML5**: estrutura semântica da página
- **CSS3**: estilo, Flexbox, Grid e layout responsivo
- **Git e GitHub**: versionamento do código
- **GitHub Pages**: publicação gratuita do site

Não foram utilizados frameworks, bibliotecas externas, JavaScript, banco de dados nem formulários.

| Projeto | Descrição | Tecnologias principais | Repositório |

| **GesTeam** | CRM para gerenciar estudos e cursos, em desenvolvimento | Next.js 14, Tailwind, Prisma, PostgreSQL, NextAuth, Docker | [kuandry/crm](https://github.com/kuandry/crm) |
| **SecureTask** | Lista de tarefas full stack com autenticação | NestJS, Prisma, PostgreSQL, JWT, Next.js, React | [kuandry/SecureTask](https://github.com/kuandry/SecureTask) |

- **GesTeam:** iniciado a partir de um curso e finalizado com apoio de inteligência artificial, que gerou cerca de 80% do código. A arquitetura, a revisão e a escolha das tecnologias foram feitas por mim.

- **ActionHub:** trabalho em grupo. Desenvolvi o back-end. O front-end foi feito por [Fernanda Feitosa](https://github.com/Fernandafss) e [Natam dos Santos](https://github.com/natamdossantos6-gif).

## Como executar localmente

Como o site usa apenas HTML e CSS, não há instalação de dependências.

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/kuandry/portfolio.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` no navegador (clique duas vezes nele ou arraste-o para uma janela do navegador).
